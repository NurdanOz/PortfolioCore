✅ Proje Hakkında

PortfolioCore, geliştiricilerin projelerini, becerilerini ve deneyimlerini rahatça sergileyebilecekleri modern ve duyarlı (responsive) bir portföy sitesidir.
Bu projede şu teknolojileri kullandık:

🎈 ASP.NET Core MVC – Güçlü ve modern bir web uygulama çatısı
🎈 Entity Framework Core – Veritabanı işlemleri için
🎈 SQL Server – Verileri saklamak için
🎈 HTML / CSS / SCSS – Ön yüzü şık ve kullanılabilir kılmak için
🎈 C# – Projenin kalbi olan programlama dili

✅ Özellikler
PortfolioCore projesi aşağıdaki temel özellikleri sunar:

🎈 Admin paneli üzerinden içerik yönetimi (projeler, deneyimler, referanslar vs.)
🎈 Dinamik olarak eklenip düzenlenebilen içerik yapısı
🎈 Ziyaretçilerin iletişim formu aracılığıyla mesaj gönderebilmesi
🎈 Hakkımda, hizmetler, istatistikler ve referans bölümleri
